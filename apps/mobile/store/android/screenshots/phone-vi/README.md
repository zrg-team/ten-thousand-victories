# phone-vi — 1080 x 1920 — Tiếng Việt

Required. At least 2, up to 8.

For the Vietnamese store listing, which is its own locale in both consoles.

6 generated by `yarn store:kit` from `store/gameplay/vi/`, in the order set by
`screenshots` in `apps/mobile/store.metadata.json`. Both consoles order by upload rather
than by filename, so upload them in the sorted order shown here.

To change which shots or captions are used, edit that file — not these PNGs.
